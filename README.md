# Productivity Management Platform

A web-based application designed to help users manage tasks, habits, and focus sessions efficiently to improve productivity and discipline.

---

## 🚀 Features

- 📋 Task Management (Add, edit, delete tasks)
- 🧠 Habit Tracker (Track daily habits and streaks)
- ⏱️ Focus Mode (Pomodoro timer)
- 📊 Analytics Dashboard (Track productivity insights)
- 🎯 Goal Tracking (Set and monitor goals)
- 📝 Notes Section (Quick brain dump)

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
